Any template can add head assets with appendMetaTag(), appendHeadCss(), appendHeadJs(), appendCssUrl() and appendJsUrl(). When it is inserted into another template they move up with it, so the page <head> collects them all.

appendCss() and appendJs() instead write an inline <style> or <script> into the template itself, so it travels with that markup. View the page source to see both.
