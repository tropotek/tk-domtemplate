DomTemplate keeps layout in plain HTML and render logic in PHP. Name the nodes PHP changes with a var attribute, then fill them in from PHP.

  • var="title": a node PHP changes.
  • var="admin?": removed unless PHP shows it.
  • var="users[]": a sample row, cloned once per item.

Every page on this site, including this one and the navigation above, is built that way. Open Source at the bottom of a page to see its PHP and HTML.
